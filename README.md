# Create: Golemancy

A Minecraft 1.21.1 NeoForge addon: manufacture golems on Create production lines and animate them
with Iron's Spells 'n Spellbooks magic.

Status: **v0.1 release candidate** (`0.1.0-rc1`). Design: [docs/SDD.md](docs/SDD.md).

## What v0.1 contains

- Two frames (Guardian, Brute) in two materials (stone, clay), three cores (Arcane, Fire, Frost)
- Parts, frames and cores made entirely with stock Create machines
- One custom block, the kinetic **Binding Altar**, with a `golemancy:binding` recipe type
- One spell slot with a curated list of four Iron's spells (Firebolt, Icicle, Ray of Frost, Shield)
- Construct energy with fuels, powered-down state, pack-up, Construct Remains and rebuilding
- Guardian and Soldier behaviour, Control Wand, three-tab configuration screen, ownership rules
- JEI category, two Ponder scenes, optional data-only Create: Wizardry integration

## Build and run

Requires JDK 21. Everything else is downloaded by the Gradle wrapper.

```bash
./gradlew build
```

```bash
./gradlew runGameTestServer
```

```bash
./gradlew runClient
```

Other tasks:

| Command | What it does |
| --- | --- |
| `./gradlew runData` | Regenerates all JSON content into `src/generated/resources` (commit the result) |
| `./gradlew runGameTestServer -Pwith_wizardry=false` | Same tests without Create: Wizardry |
| `./gradlew runClient -Pwith_wizardry=false` | Client without Create: Wizardry |
| `./gradlew runClientSmoke -Psmoke=m4_tour` | Scripted client run: builds a showcase, takes screenshots, exits |
| `.venv/Scripts/python tools/art/build_all.py --check` | Rebuilds every texture, model and contact sheet; verifies reproducibility |
| `.venv/Scripts/python tools/make_structures.py` | Rewrites GameTest and Ponder structure files |
| `.venv/Scripts/python tools/check_lang.py` | Checks every translation key used in code exists |

The art tools need Python 3.12+ with Pillow (`python -m venv .venv`, then
`.venv/Scripts/python -m pip install Pillow==11.1.0`).

IntelliJ IDEA: open the folder as a Gradle project; ModDevGradle creates the run configurations.

| `docs/` | SDD, PROGRESS (milestone gates), DECISIONS, VERSIONS, PLAYTEST |
